# MLOps Engineer Curriculum Overview

This repository provides lectures, exercises, and projects to help learners meet the expectations outlined in the role requirements. Use the mapping below to connect job requirements with specific modules and hands-on deliverables.

## Requirement-to-Module Mapping

| Job Requirement | Curriculum Coverage |
| --- | --- |
| Design and implement CI/CD pipelines for ML model deployment | Module 02 - CI/CD for Machine Learning<br>Module 06 - Automation & Orchestration<br>Project 01 - CI/CD Pipeline Automation |
| Automate model training, validation, and deployment workflows | Module 06 - Automation & Orchestration<br>Module 08 - Production Operations<br>Project 1 - End-to-End ML Pipeline |
| Implement model monitoring and drift detection systems | Module 03 - Model Monitoring & Observability<br>Module 08 - Production Operations<br>Project 02 - Model Monitoring Platform |
| Build automated retraining pipelines triggered by drift or performance degradation | Module 06 - Automation & Orchestration<br>Module 08 - Production Operations<br>Project 04 - Automated Retraining Pipeline |
| Develop A/B testing and canary deployment frameworks for models | Module 08 - Production Operations<br>Module 02 - CI/CD for Machine Learning<br>Project 5 - LLMOps Playbook |
| Implement model versioning and lineage tracking systems | Module 05 - Experimentation & Reproducibility<br>Module 06 - Automation & Orchestration<br>Project 03 - Experimentation Platform |
| Create data validation and quality checks in ML pipelines | Module 04 - Data Quality<br>Module 02 - CI/CD for Machine Learning<br>Project 03 - Validation and Lineage |
| Design and maintain model governance and compliance frameworks | Module 07 - Governance & Compliance<br>Module 09 - Security for MLOps<br>Project 05 - MLOps Governance Program |
| Implement GitOps practices for ML infrastructure | Module 02 - CI/CD for Machine Learning<br>Module 06 - Automation & Orchestration<br>Project 4 - GitOps for ML Governance |
| Develop model performance monitoring dashboards | Module 03 - Model Monitoring & Observability<br>Project 02 - Model Monitoring Platform |
